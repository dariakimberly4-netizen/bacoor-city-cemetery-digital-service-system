# Bacoor City Cemetery Digital Service System

Browser-based prototype for the City Government of Bacoor — City Cemetery Office, modeled on the supplied Citizen’s Charter.

## Included
- Staff login demo
- Dashboard and application registry
- New Lease, Renewal, Columbarium, Cremation, Bereavement Room, and Chapel workflows
- Service-specific document checklists
- Automatic cemetery reference numbers
- Burial space / niche inventory
- Scheduling
- Payment-order records (payment remains with City Finance)
- Contract / certificate and release tracking
- Reports and CSV export
- Browser offline data storage
- Responsive mobile layout

## Important
This is a functional prototype, not yet a production government information system. A live deployment should use approved secure authentication, a shared server database, audit logs, privacy controls, secure document storage, official payment integration, backups, and formally verified fee configuration.

Some fee lines in the supplied Citizen’s Charter PDF are visually/line-break ambiguous. Those items should be verified against the current approved fee schedule before production automation.
